# 模式 25 / 26：标准方波与标准正弦

界面每个通道的模式列表新增 **25 标准方波** 和 **26 标准正弦**。两者均支持设置 1 kHz；原有模式 1～24 的波形内容不变。需要配套的新 FPGA bitstream，不能只更新上位机。

## 使用

1. 下载 `bitstreams/AD9106_basic_1khz_20261024_112900.bit`。
2. 关闭并重新启动 `tools/start_firing_gui.cmd`，然后刷新浏览器，确保 Python 后端也已更新。
3. 选择模式 25 或 26，频率框单位为 **kHz**，填写 **1**。
4. 设置幅值、偏移；方波设置占空比，正弦可设置相位。检查预览后发送。

幅值是中心到峰值，输出范围为 `偏移 − 幅值` 到 `偏移 + 幅值`。例如方波幅值 2 V、偏移 2 V 对应 0～4 V。电压仍按现有 ±10 V 标定换算，实际值需结合板卡测量。

可直接导入 `waveforms/example_basic_1khz.json`：DAC1 输出 0～4 V 方波，DAC2 输出 ±2 V 正弦，DAC3 输出 ±1 V 方波，DAC4 输出 ±3 V、90° 相位正弦。四路请求频率均为 1 kHz。

沿用当前设置：每次触发播放 **两遍预览单元**，界面组数决定触发几组，间隔表示一组结束后的等待时间，默认 1 s。公共预览单元可能包含较快通道的多个周期。

## 支持范围

| 项目 | 模式 25 方波 | 模式 26 正弦 |
|---|---|---|
| 生成方式 | FPGA 定时写常量，RAMUPDATE 同时提交 | AD9106 内部 DDS |
| 1 kHz | 50% 占空比可用 | 实际约 1000.195742 Hz |
| 参数 | 频率、幅值、偏移、占空比 | 频率、幅值、偏移、相位 |
| 多通道 | 各路频率可不同，但联合边沿必须满足时序预算 | 多路正弦必须使用同一频率 |
| 相位 | 当前固定 0° | 独立配置 |

当前 SPI 保持 1 MHz。每次切换需预写四路常量、四路增益，再统一提交，因此所有通道合并后的相邻事件间隔必须至少为 **300 µs**。单路 1 kHz 方波可用约 30%～70% 占空比；多路不同占空比会产生更多边沿，须按联合事件检查。程序拒绝过密边沿，不自动改变脉宽。

新模式可以与其他通道的直流输入一起使用；暂不与原有动态 SRAM 模板混合播放。选择不支持的组合时，预览显示原因并禁止发送。不会修改其他通道参数。

DDS 24 位频率字在 148.5 MHz 下取 113 时，输出 1000.1957416534424 Hz，误差约 195.742 ppm。界面显示量化后的实际频率。这个数值为标称时钟下的计算值，未计入晶振误差。

## 软件和硬件分工

PC 在 `tools/basic_waveforms.py` 中计算 DDS 寄存器、公共周期和完整事件表，检查电压与最短事件间隔。事件表一次性经原有串口协议写入 FPGA。PC 只负责组间等待和再次触发，不负责 500 µs 边沿定时。

FPGA 的 `ad9106_basic_sequencer` 使用现有 100 MHz 系统时钟执行事件表；该模块在 `AD9106.v` 中实例化，无新增顶层引脚。预写下一事件的八个影子寄存器后，在指定时刻发 RAMUPDATE。首个事件启动 TRIGGER，结束事件将四路常量和增益清零并拉高 TRIGGER。播放期间不会自动将 RUN 置零。重新触发会从事件表恢复增益和初始电平。

结束后方波回到零码；正弦交流分量归零，已设置的数字偏移可保留。停止按钮会额外清除偏移。零码的实际电压取决于后端标定。

DDS 使用 `WAVE_SEL=2 / PRESTORE_SEL=3`，配置每个通道的 `DDS_CYCx`。有限重复保持 `0x1F=1`、`0x2A=0x2B=0x0101`。公共周期为完整 DDS 周期和触发延迟留出余量。

手册依据：[AD9106 Rev. C](https://www.analog.com/media/en/technical-documentation/data-sheets/AD9106.pdf)，第 22 页影子寄存器与 RAMUPDATE、第 26～27 页增益/偏移及有限 DDS、第 44～45 页波形源选择和周期配置。DDS 是共享频率资源。

## FPGA 内部配置地址

通过既有 SCENE_WORDS 命令写入，以下是 FPGA 虚拟地址，不会发到 AD9106 SPI：

| 地址 | 含义 |
|---|---|
| `0x7100` | 0 禁用，1 启用事件播放 |
| `0x7101` | 事件数量，2～64 |
| `0x7200..0x747F` | 64 个事件，每个 10 个 16 位字 |

每个事件依次为：绝对时间高 16 位、低 16 位（100 MHz 时钟计数），DAC4/3/2/1 常量，DAC4/3/2/1 增益。最后一个事件的八个数据在硬件中强制为零。第一事件距启动 300 µs，供 SPI 预装数据。COMMIT/RETRIGGER 启动播放，BEGIN/ABORT 取消播放；播放时读回等待结束，以免插入 SPI 操作破坏事件时间。
