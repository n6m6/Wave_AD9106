# 节律调制实验

节律调制直接集成在原通道卡的“模式”下拉框中，没有独立实验面板：

- **27 节律调制 · Vin 方波 / Vgate 正弦**
- **28 节律调制 · Vin / Vgate 双方波**

原有 1～26 的编号保持不变。选择 27 或 28 后，自动启用当前 Vin / Vgate 配对；没有有效配对时使用相邻 DAC1/2 或 DAC3/4，并关闭其他通道。该功能生成激励，发放响应仍由外接示波器记录。

默认 Vin 占空比 50%、ON 时间 20 μs，即单周期 40 μs、频率 25 kHz；Vgate 默认 25 kHz，方波时占空比也为 50%。观察窗默认 200 μs，包含 5 个 Vin 周期。新建输出默认 0～1 V，对应通道卡“幅值”0.5 V、“电压偏移”0.5 V。27 / 28 相互切换时保留已有节律参数，便于在相同条件下比较两种组合。

1. 在要使用的通道卡上选择模式 27 或 28，配对卡会同步切换模式。
2. Vin 卡设置 ON 时间和占空比，Vgate 卡设置频率；双路方波时，Vgate 也有独立占空比。两张卡分别设置“本路初始相位”，其差为 Vgate − Vin。
3. 核对两路幅值、电压偏移和观察时长。参数修改后，右侧原波形预览区自动重新编译，不需要额外应用按钮。
4. 显示“可发送”后沿用原串口检测和发送流程。发送后两路同步开始，一个观察窗结束后归零，下一次触发重新从所设初始相位开始。切换回其他模式即可退出节律输出。

两路只联动模式和共同观察时长，ON 时间、频率、相位、幅值和偏置分别设置。预览中同时显示两路实际采样、频率差、初始相位差和窗内相位漂移。编译失败时仍显示理论形状帮助调整，禁止发送。旧独立面板保存的 JSON 导入网页时会自动转换为对应的 27 / 28 模式。

## 上升与下降时间

模式 27 的 Vin 方波、模式 28 的 Vin / Vgate 方波均可在原通道卡独立设置“本路上升时间”“本路下降时间”，两者范围都是 **0～1 μs**，默认 0（数字跳变）。模式 27 的 Vgate 为连续正弦，不显示脉冲边沿控件。

上升、下降采用线性变化，表示完整低电平到高电平或高电平到低电平的时间，并计入原 ON 时间。例如 ON=20 μs、上升=0.4 μs、下降=0.6 μs，高电平平台为 19 μs；周期、频率和上升沿起点不变。两段边沿之和不能超过各路 ON 时间，超出时拒绝编译，不自动裁短。原本未填写边沿的场景仍输出理想方波。

预览、下发采样和导出的 CSV 使用相同的边沿数据。非零边沿短于所选 DAC 采样间隔时，预览给出“可发送 · 请检查细节”的精度警告；可缩短观察窗或增大边沿时间。0 μs 代表不插入数字斜坡，模拟电路的实际边沿仍以实测为准。边沿设置作用于周期内的方波，观察窗结束仍按既有规则归零，可能截断当前周期。

## 相位差和频率差

Vin 的上升沿起点为相位 0°。初始相位差定义为 `φgate − φvin`，正数表示 Vgate 提前；正弦的 0° 是向上通过中心电压，+90° 是峰值。因此在同频时，+90° 的 Gate 正弦峰值对齐 Vin 上升沿起点。两路方波时，+90° 表示 Gate 提前四分之一个 Gate 周期。

频差为 `Δf = fgate − fvin`。频率不同时，相位差不能始终固定，观察窗中按下式漂移：

```text
Δφ(t) = Δφ(0) + 360° × Δf × t（秒）
```

例如 Vin=25 kHz、Vgate=26 kHz，频差为 +1 kHz，200 μs 内相位差增加 72°；Vgate=24 kHz 时减少 72°。预览报告初始相位差和窗内漂移，初始角度显示为等效的 −180°～180°。新模式直接使用各路相位角，变频时保持所填初始相位，不再通过隐藏的微秒时间偏移调相。

## 输出方式与范围

两路均从 SRAM 采样输出，共用 DAC 采样时钟。指定观察窗内按各自频率、初始相位连续生成，不要求频率为整数倍，也不会在每个 Vin 周期重置 Gate 相位。该路径绕过标准方波 FPGA 事件提交最少 300 μs 的限制，不改变正常模式 25/26 的原有实现，不需要重新生成 bitstream。

每次触发仅播放一次，末尾附一个数字零码采样。`0x2A/0x2B` 均为 0，整个观察窗不会重复两遍。触发组数大于 1 时，组间保持原有间隔，但这些组不会拼成连续拍频。示波器可继续记录刺激结束后的响应，通道卡的“观察时长”指激励输出窗，不是示波器采集时长。

两路共享 4096 个采样点，HOLD 范围 1～16。148.5 MHz 时钟下，两路不同采样数组通常最多容纳约 220 μs；默认 200 μs 使用 3962 点，HOLD=15，采样间隔约 0.10101 μs，对 25 kHz 约为每采样 0.909°。每个动态载波至少 32 点/周期，方波高低电平不能短于一个采样间隔；至少观察每路一个完整周期。相同数组可共用 SRAM，但调相或调频后可能需要两份存储，容量将重新检查。

过长观察窗或不够的采样分辨率会在发送前拒绝，不会偷偷改变频差、相位差或频率。1 kHz 频差的完整拍频周期为 1 ms，当前 200 μs 观察窗只覆盖其中一部分；不能用多次重新触发替代一段连续的 1 ms 激励。若需要更长的连续节律，需要进一步扩展采样/存储或 FPGA 波形生成架构。预览为编译后的名义电压，模拟输出精度仍需示波器核对。

## 保存与命令行

示例场景：

- [Vin 方波 / Vgate 正弦](../waveforms/example_rhythm_square_sine.json)
- [Vin / Vgate 均为方波](../waveforms/example_rhythm_square_square.json)

场景直接保存通道模式 `mode: 27` 或 `mode: 28`，两路 `duration_us` 为共同观察时长。Vin 的 `parameters` 使用 `rhythm_on_us`、`rhythm_duty_percent`，Vgate 使用 `rhythm_frequency_khz`，双方波模式的 Gate 另有 `rhythm_duty_percent`；两路相位分别使用 `rhythm_phase_deg`。新场景不需要顶层 `rhythm_modulation` 开关。旧场景仍可直接通过命令行编译。

方波的边沿保存在各通道 `parameters.rise_time_us` / `parameters.fall_time_us`，单位为实际 μs，允许缺省或 0～1 的数值。正弦不接受这两个脉冲边沿字段。

```powershell
python tools/ad9106_firing.py program --scene waveforms/example_rhythm_square_sine.json --out .uart_sim/rhythm_plan
```

编译计划的 `rhythm_modulation` 给出实际观察时长、频差和相位漂移；各路 CSV 包含实际采样时刻和末尾零码点。CSV 是激励数据，不是测量到的发放波形。

不带 `--port` 时仅导出计划，不连接硬件。
