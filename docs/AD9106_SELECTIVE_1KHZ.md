# 选择性支持 1 kHz，保留原有波形生成方式

本次不启用 SPI 实时逐点输出。使用 AD9106 原有 SRAM 播放功能，仅在能保留有效波形时省略末尾零码等待数据，由 PAT_PERIOD 计时完成整个单元。

## 使用

重启 Python 上位机服务并刷新浏览器。普通模式在“包络频率 / kHz”中填写 1；静态扫描在模板长度中填写 1000 µs，开始时刻和脉宽仍按 µs 设置。可导入 [静态扫描 1 kHz 示例](../waveforms/example_static_1khz.json)。

无需重新综合或烧录，本次没有修改生产 RTL；继续使用此前两遍播放版固件。触发组数为 1 时仍播放两个完整单元，1 kHz 对应每单元 1 ms、每组 2 ms，组间等待从两遍结束后计算。

## 编译规则

- 优先使用原来的完整 SRAM 周期编译路径，原来可用的配置不改变采样方法。
- 仅在原路径无法容纳时尝试省略末尾零码段。保留从单元开始到波形归零的全部样点，包括开始前等待、内部间隔、每个脉冲和边沿；归零后至少保留一个零码样点。
- 末尾必须是与 DAC 空闲输出一致的数字零码。持续非零尾段、无法证明尾段归零的解析波形、非整周相移不会被截断。
- 新增路径不使用原先的“把过窄平台拉成一个样点”修正。任何非零持续时间的分段短于一个采样间隔，或有效数据超过共享 4096 点，都拒绝该配置。
- 正常 DAC 采样/12 位量化仍然存在；“保留细节”指不额外删点、合并事件或人为加宽脉冲，不代表连续时间无限精度。
- 拒绝发生在串口上传之前，不修改器件当前输出，不自动替用户更改频率或其他通道配置。界面保留待编辑参数并提示原因；需要恢复该路原频率后才能发送整个场景。
- 四路共用时钟、PAT_PERIOD 与 SRAM；单路通过不代表任意四路组合均通过，Vin/Vgate 配对和不同频率混用仍需联合编译。

## 示例结果

静态扫描 Vin：周期 1000 µs，10 µs 开始，宽度 10 µs，名义幅值 5 V；Gate 恒压 8 V。

- DAC 时钟仍为 148.5 MHz；HOLD=1，采样间隔约 6.734 ns。
- 全周期等效 148500 个采样位置，只需存入前 2971 点；其余 145529 个位置为零码等待。
- `0x28=0x0131`、`0x29=0xC15C`，周期为 `49500 × 3 / 148.5 MHz = 1 ms`。
- DAC3 SRAM 起止地址为 0..2970；`0x2A/0x2B=0x0101` 仍表示两遍。
- 预览按完整 1 ms 横轴绘制，显示末尾零码等待时长，不会将短脉冲拉伸到整个窗口。

依据：[AD9106 官方手册](https://www.analog.com/media/en/technical-documentation/data-sheets/AD9106.pdf)第 25 页模式周期、第 27–28 页 SRAM、第 29 页空闲输出及第 30 页图 49。芯片实际波形和重复次数仍需板上验证，数字仿真不能证明此前波形串问题已经消失。

## 适用范围扫描

默认幅值、默认时序、单路条件下扫描 512 个组合（原有 504 个组合，加四种拓扑的静态 Vin/Gate）：105 个动态组合可编译为 1 kHz，188 个组合本身是直流，219 个动态组合拒绝。直流不计作 1 kHz 动态波形。

下表只表示该模式**至少有一个变体或分段**通过，不表示所有变体和配对均通过。

| 拓扑 | 可通过的 Vin 模式 | 可通过的动态 Vgate 模式 |
|---|---|---|
| 3 | 9、11、12、15、21、24 | 4、15 |
| 5 | 9、11、12、15、21、24 | 4、15、18 |
| 6 | 9、11、12、15、21、24 | 4、15、18 |
| 7 | 11、12、15、21、24 | 4、11、15、18 |

逐组合结果及拒绝原因：[support.json](firing_verification/selective_1khz/support.json)。修改脉宽、相位、幅值、偏置或其他通道后，需重新编译判断。

复现扫描：`python tools/report_1khz_support.py`。测试：`python -m unittest discover -s tools -p 'test_*.py'`。顶层验证：`powershell -ExecutionPolicy Bypass -File tools/test_firing_uart.ps1 -Top -Scene waveforms/example_static_1khz.json`。

## 验证记录

22 项 Python 测试通过，包括 1 kHz 完整采样序列与“SRAM 前缀 + 隐式零码尾段”的逐点一致性、拒绝过窄细节、拒绝非零尾段、拒绝后无串口上传以及原有场景回归。浏览器离线检查通过 JavaScript 语法及 1 ms 横轴上的 10–20 µs 脉冲位置验证。

完整 BD 顶层 XSim 通过：449 帧 UART、3019 笔 SPI 写入全部匹配；每次触发后观察 30 ms 无额外写入或触发。独立读取捕获的 SPI 寄存器和 SRAM，重建完整 1 ms 单元也通过。记录：[顶层日志](firing_verification/selective_1khz/firing_uart.log)、[SPI 重建图](firing_verification/selective_1khz/four_channel_spi_reconstruction.png)、[校验结果](firing_verification/selective_1khz/observed_summary.json)。重建图依据手册的空闲零码行为补齐末尾等待，不是示波器实测或 AD9106 模拟电路仿真。
