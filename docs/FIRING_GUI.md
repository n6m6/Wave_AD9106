# 四路波形可视化控制台

双击 [start_firing_gui.cmd](../tools/start_firing_gui.cmd)，或在工程目录运行：

```powershell
.\.venv\Scripts\python.exe tools/firing_web.py
```

程序在本机启动服务并打开默认浏览器；命令行会打印实际地址，例如 `http://127.0.0.1:53324/`。保持命令行窗口运行，关闭窗口即停止服务。页面只绑定 `127.0.0.1`，不对局域网提供控制接口。要在不自动打开浏览器时启动：`python tools/firing_web.py --no-browser`。

波形配置和预览只依赖 Python 3.8 或以上版本的标准库及浏览器。**串口检测和发送**另需：

```powershell
.\.venv\Scripts\python.exe -m pip install pyserial
```

页面顶部每 6 秒刷新本机串口列表，也可点“刷新列表”。选择串口后点“检测设备”：程序发送一帧未知命令 `7F`，只有收到本项目解析器返回的 `03`（未知命令）、并通过序号和校验验证，才标记已连接；该探测不会产生 SPI 写入。切换串口后连接标记会清除，需要重新检测。没有连接标记时不能发送。

四张通道卡分别设置启用状态、拓扑、23 类模式、Vin/Vgate、实验变体、同一序列的分段、频率、幅值、偏移和相位。“高级时序参数”可修改脉宽、间隔、上升沿、Gate 偏置及多档电压等。实验变体对应 HTML 中叠加绘制的各条不同实验曲线；`sequence/low/mid/high`、`near/far/single` 等序列分段由对应模式显示。频率填写 **kHz**，含义是整段模板的包络重复频率；幅值填写名义 **V 绝对峰值**，负向波形依原始方向缩放。“原图幅值”将该路幅值设为当前实验峰值与 10 V 中较小者。改变拓扑或模式会清除该路高级时序覆盖值。

发放模式在原通道卡上增加少量直接参数，不改变模式选择与发送流程：

- Vin、Vgate 的脉宽分别设置，只显示当前信号适用的字段。脉宽包含上升、下降沿；**新增字段填写实际 μs**，留空沿用原模板。03 的 Gate 脉冲组、20 的负 Vin 脉冲组同时支持 on 持续时间与间隔。
- 03、20、22 的“脉冲间隔”从前一脉冲完全回到基线算到下一脉冲开始；改变脉宽不改变所填间隔。03 另有 Vgate 脉冲数量，20 另有 Vin 脉冲数量。
- 05 的 Vgate、07 的 Vin 分别提供第一段电压、第二段电压、第一段持续时间、第二段持续时间。时间均为实际 μs，修改一段不会挤占另一段。保留原模板形状：05 拓扑 7 为两个方波平台，其他拓扑为从第一电压斜坡到第二电压后保持；07 从 0 V 斜坡到第一电压，再以第二电压保持。输入电压直接作为名义输出，幅值框停用，偏移仍叠加。
- 06 的 Vgate 开始电压、结束电压独立设置；Vgate 脉宽控制完整斜坡持续时间，均使用实际单位。
- 11 的 Vin 为方波脉冲列、Vgate 为连续正弦。Vin 内部方波频率（kHz）、占空比（%）、脉冲数量和 Vgate 正弦频率独立设置；脉宽 = 1000 / 频率(kHz) × 占空比 / 100（μs）。包络频率只控制整组时窗，容纳不下时应降低包络频率扩大时窗。
- 12 输出 **Vgate 恒压**；实验变体仅有“快脉冲”和“慢脉冲”，每次只输出选中的一组。Vin 同样设置内部方波频率、占空比和脉冲数量，不再把两组拼在一个时窗。切换 11、12 的变体时，清除 Vin 频率/占空比及旧脉宽、间隔覆盖，恢复所选变体的脉冲节律；脉冲数量和 Vgate 正弦频率保留。
- 23 显示为“兴奋性阻断”。
- 15 的三档 Gate 电压分别填写；21 的三档 Vin 电压也可分别填写。填写后这些值作为名义输出电压，幅值框停用，偏移仍会叠加；未填写的档位沿用原幅值下的模板电压。
- 配对后，上述新增参数会同步到对应通道，两个脉宽仍是不同字段。模式、实验变体、序列分段均双向联动。切换模式时两路恢复新模式的默认变体、分段、时序和幅值，Vin/Vgate 角色保留。其他高级参数及原“同步两组 Vin/Vgate 配对”按钮保持原流程。
- 每条通道显示配对状态：同组恰好两条启用通道、分别为 Vin/Vgate，且拓扑和模式一致时，显示配对对象并启用模式联动；否则显示“当前未配对”，切换模式只修改当前通道。实际发送仍需通过原有时序一致性检查。

其余原高级参数仍使用参考模板坐标。旧 JSON 的 `width_us`、`levels_v` 等可继续载入，新增字段优先；模式 12 的旧分段在页面中改为当前快/慢变体选择，导入后请核对。11 的 Gate 统一正弦、12 拆组及恒压为实测协议修正。实测时序仍有 DAC 采样量化误差。

“理论波形 · 当前配置不可发送”说明四路联合编译失败：页面仅画出各路模板帮助检查，不能发送。上方会给出具体原因，例如配对变体或时序不一致、脉冲超出时窗、SRAM 容量或采样分辨率不足。修正后自动重新编译；显示“可发送”才是已通过编译的预览。

“同步两组 Vin/Vgate 配对”把 DAC1 的拓扑、实验、时序、频率及相位复制给 DAC2，把 DAC3 的对应设置复制给 DAC4，并令每对信号分别为 Vin/Vgate。也可手动选配对 A/B；编译器要求一组恰好有一条 Vin、一条 Vgate 且时序参数一致。只选择单路时，配对设“无”。其他通道可以使用不同频率；实际是否能够联合输出由页面实时编译决定。编译失败时仍会画出可生成的单路模板预览，并禁止发送；错误文字会说明容量或参数问题。

页面右侧显示**真实编译后数字采样**对应的四路名义电压，还给出各路频率、共享 SRAM 已用点数、HOLD 和频率误差。细窄平台在图中使用每像素的最小/最大值绘制，避免窄脉冲在预览中消失。“下载 JSON”可在本机留存场景，“导入 JSON”可载入现有场景。“保存到工程”写入 `.uart_sim/firing_scene.json`，下次打开页面继续使用；发送前也会保存一次，并在 `.uart_sim/firing_web_plan/` 导出指令及四路 CSV。

确认预览无误后点“发送四路配置”。浏览器显示每帧回包进度，FPGA 收齐并提交后四路公共触发启动。点击“停止输出”会发送 `43` 指令，已运行的场景也可停止；清零的数字码与板级实际输出零伏之间仍需实测校准。如果上传失败，界面会清除已检测连接标记，应检查设备状态、刷新串口并重新检测。

# 静态扫描与单次播放

通道模式新增“24 静态扫描”。将一对 DAC 分别设为 Vin 和 Vgate，并使用“同步两组 Vin/Vgate 配对”；Vin 的“幅值 / V”是脉冲电压，Vgate 的“幅值 / V”是恒定电压。展开“高级时序参数”可配置 `width_us`（脉冲持续时间）、`start_us`（起始时刻）、`period_us`（本次完整波形时窗，默认 100 µs）。脉冲必须在时窗结束前归零。静态扫描通道须使用同一个时窗，不能与其他非直流模式混合在一次播放中，以免在同一次触发中出现多个脉冲。

界面上的“24”只是模式编号；每张 DAC 卡的“输入信号”才决定该通道输出 Vin 还是 Vgate。点击“DAC3 Vin / DAC4 Vgate 静态扫描”可一键建立安全初值：DAC3 的“Vin 脉冲电压 / V”与“脉冲宽度 / us”可调，DAC4 的“Vgate 恒定电压 / V”可调。按钮同时关闭 DAC1/2，初始 Vin 为 1 V、Vgate 为 0 V，发送前应按实验需要修改。切换到模式 24 时保留已有 Vin/Vgate 角色，之后仍可在“输入信号”中自由切换。

当前采用芯片有限次 SRAM 播放，FPGA 不再执行截止计时或自动 RUN 清零。PAT_TYPE=1、四路重复计数=0；COMMIT 与再次触发 44 均仅写 RUN=1、RAMUPDATE=1，随后拉低 TRIGGER。PC 控制重复次数和完整波形之间的间隔；正常结束后 RUN 保持 1、TRIGGER 保持低。停止按钮拉高 TRIGGER 并将数字增益/偏移/常数归零，不清 RUN。详见 [当前流程](AD9106_SINGLE_PATTERN.md)。

这些设置不能替代对 DAC 后级电压、直流零点和器件安全工作区的实测。工程中 UART RX/TX 已约束到 A21/C20；本次解析器新增 `44` 命令后仍须重新生成并下载 bitstream，不能使用旧版本。
